## Scope and evidence

The release audit covered the complete changes since `origin/main`
(`3787fe3`), including the incoming uncommitted Turbo/Metal work and the
gallery migration. The primary reviewer inspected the related engine,
server, model loading and cache, Metal kernels, library persistence,
generation lifecycle, update checker and app UI implementations, not only
their changed lines. The working tree and incoming untracked files were
preserved before editing.

fixtures, weights, images and machine-specific logs are not release assets.
The public [measurement report](../../benchmarks/release-0.5.0.md) links
the compact raw timings, source digests and quality measurements.

## Primary audit assessment

The primary reviewer inspected the related implementation and performed the
local checks above. Metal gain and bias lengths are checked before kernel
dispatch. Library locking, atomic writes, legacy migration, format-2
compatibility, cancellation/save ordering, main-actor state, model unloading
and bounded caches were reviewed with their tests. HTTP loopback,
origin/host and input limits and the bounded HTTPS update checker were also
reviewed. There are no new dependencies or downloaded weights in the diff.

The primary review initially underestimated a typography regression in the
FP16 candidate. Independent review correctly treated the reproducible loss
of requested sign text as Medium. The primary reviewer accepted the finding
and restored the official BF16 path, then reran the full Python suite,
failing image fixture and final Turbo measurements. The rejected FP16
source and evidence remain locally preserved; it is not a production option.
[Quality findings](../../benchmarks/release-0.5.0.md#quality-review) distinguish
numerical closeness from actual prompt-following quality.

Remaining validation limits: other Apple chips, 16 GB Macs, runtime on
macOS 15, CUDA comparison, long memory soaks and perceptual user studies
were not run. Builds are unsigned for distribution; this release supplies
source only and does not implement automatic installation.
